数据预处理

去除无意义/无影响的features

不难注意到 passengerid是无关的变量。
Cabin，Name，Ticket由于信息复杂，我还不会处理，删了。

需要注意的是，train和test的处理要一致

填充nan数据

利用info可以得到是否有nan数据

一般用median（中位数）或者mean（均值）将nan替换

分类编码

通过info我们得知，sex 和 embarked 的类型都是 object 字符串，不能直接拿来训练模型，因此需要编码。

在Tatanic中，sex 和 embarked 都是分类，倘若种类比较多而直接给他们赋值成0,1,2,3,4…会有大小关系，人为引入了序，可能影响模型预测结果。
