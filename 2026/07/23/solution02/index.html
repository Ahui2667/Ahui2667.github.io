线性基

模板：洛谷P3812

给定全集Ω，将Ω二划分成A，B。
设X和Y分别是A和B的异或和，那么设S=X^Y是全集的异或和。
求：X + Y = X + S^X = X^X^S + 2X&(X^S) = S + 2X&( (X&S) | (X&S) )
= S + 2(X&~S) 的最大值。

将全集中的 x 做映射 y = x&S 。由分配律知，X&S = Y。
只需要求映射后的集合中的子集的最大异或和 Y 。
ANS = S + 2Y 即为所求。

G

https://ac.nowcoder.com/acm/contest/133877/G

部分暴力部分聪明 + 数论（类欧拉函数）

给定节点 1 ~ +∞ 的带权有向图，对 i < j ，有一条从i指向j的权为gcd(i,j)的边。
cost(i,j)为从i到j的路径的最小权和。
求sigema(i=l;i<=r;i++;cost(i,n))

注意到cost(i,j)<=2，若i和j之间有素数。
考虑小于n的最大素数p：

  • p>=r ，ans=2(r-l+1) - (calc(r,n) - calc(l-1,n))
  • r>p>=l，ans=2(p-l+1) - (calc(p,n) - cacl(l-1,n)) + get(p+1,r,n)
  • l>p, ans=get(l,r,n)

get(l,r,n)为sigema(i=l;i<=r;i++;cost(i,n))，用暴力枚举做。

calc(x,n)为1~x中与n互质的数的个数，用容斥定理做。

https://ac.nowcoder.com/acm/contest/133877/G

拓扑排序数 + 排序的逆

模板：AT_abc041_d

给定n排列的置换 P ( P(A)i = Api ) ，设排列A逆序对个数为f(A)，求使得abs(f(A)-f(P(A)))最大的n排列A的个数。

注意到：只有当 pi > pj ( i < j ) 时对abs有贡献，分为两类：

    1. Api > Apj 相较于原序列，逆序对数+1
    1. Api < Apj 相较于原序列，逆序对数-1
      想要让abs尽可能大，就要让产生贡献的pair只有一个类型。
      如第一类：相当于求对任意的 pi > pj ( i < j ), 都有 Api > Apj 的排列A的个数。由对称性知（简证：对A做取相反数的映射，发现两类是一一映射），两类的排列数一致。

怎么求这个排列数呢？设 g(x) 为x在排列中的下标，那么排列A的函数a与g是一一映射。
若Api > Apj 意味着在排列G中pj必须在pi的前面，要求的排列数就等价于求拓扑排序数。

H

https://ac.nowcoder.com/acm/contest/133877/H

构造+异或

构造做法

0 ~ (1 << n)-1 能否去掉两个数a,b，使得剩下的数能两两配对，使得两个数的二进制表示恰好有两位不同，有的话给出构造。

若x,y是满足条件的一对数，那么x和y的1的个数的奇偶性一致。
0 ~ (1 << n)-1 中1的个数是奇数的有偶数个，偶数的也有偶数个。
那么去掉的两个数a,b的1的个数的奇偶性也要一致才行。

注意到x^y与x只有在0，1位的数不同，当且仅当y中1的个数为2。

从n=0，且不限制a，b的角度看这个问题：

  • n=0 …问题没有意义
  • n=1 …去掉0，1
  • n=2 …去掉1，2
  • n=3 …去掉3，4

…考虑x^3，在mod 4视角看，0^3=3,1^3=2，因此只需去掉某个x,x^3对就行。
构造只需输出剩余的所有x,x^3即可。

…写过几个例子有这样一个猜想：x^y,x能恰好将所有的0 ~ (1 << n)-1 中的数覆盖。那么a,b如果是符合条件的a,b就可求出y=a^b，构造也就轻而易举。

…考虑a,b 1的个数的奇偶性相同但是a,b不是符合条件的配对。
将所有数都异或一个a，那么配对关系不变。
由于我们只关注两数在同一位的数是否相同，可以将所有的数做一个不改变1的个数的映射，不妨将b所有的为1的位移到最低位。
相当于去掉了(0,2^(2k)-1)，对于x>2^(2k),x与x^3符合条件。
对于x < 2^(2k)-1 ，对k递归构造，v=2^(2k)-1,那么(v,2v),(2v^3,4v)即可。
